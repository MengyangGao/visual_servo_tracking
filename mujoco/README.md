# mujoco-servo

Python package for the repository's MuJoCo visual-servo and manipulation platform.

It provides IBVS/PBVS/Hybrid objectives, color and open-vocabulary RGB-D perception, replaceable MuJoCo Menagerie robots and target models, position/velocity/torque/impedance control, physical contact grasp verification, reactive pick-and-place policy, and fixed-base Unitree G1 upper-limb primitives.

Installation, demos, media, model attribution and measured acceptance results are documented in the repository-level [`README.md`](../README.md) and [`ASSETS.md`](ASSETS.md).

The package does not implement real-robot transport, emergency-stop hardware, certified collision avoidance, biped balance or locomotion.
